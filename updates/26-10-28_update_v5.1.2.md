## What was done

**PLAN's form (r261027-az7o)**
- **The block chips** no longer wear their Todoist label's colour. b1, b2 and b3 have one (red, yellow, green), so three
  chips looked lit and the picked one was lost among them; 4–6 had none. Now all six are plain and only the picked one is
  lit, in PLAN's accent. The tasks still carry `@b1`… as before; DO's block tiles keep the label colours (not asked).
- **The priority row** is off by default (`plan.formFields.priority: false`). A task goes to Todoist with
  `plan.defaultPriority` (2, "optional", as the row's default was). The switch stays in settings → plan → task form, so the
  row can come back. His ROOT desktop has no stored form-fields override, so the new default reaches it as is.
- **A queue row** names a priority only while the row is on, and now by its value: it read the value as an index, so
  "optional" (2) showed as "mandatory" and "urgent" (4) as nothing.

**The desktop (r261027-zf0v)**
- **Today** is on the rail whatever the bar style: dock, floating pill, bottom bar or hidden. It needed the dock (`todayFits`,
  and `.tab-today`'s rules); now it needs the rail and 1100px.
- **The dock** keeps a list of any length. On the rail (a wide window, `desktopMode: rail`) every app in it has a tab, in
  its order; a phone's dock still holds five (`Prefs.SCHEMA.dock.phone`) and shows the first five of a longer list, the rest
  in its R. Settings stops a sixth only off the rail, and its note says so. The window crossing 880px, or the layout
  switching between frame and rail, re-draws the bar (`railUp`, `Shell.railUp`).
- **Decided here:** on the dock, the rail now lists the dock's apps, then settings and the R. Since 4.25 it listed every app
  after the dock's, so with every app already there the dock's five only set the order; the floating pill's rail always
  listed only its own apps, which is the one he was on. The R still opens every app. His ROOT desktop's dock is do · log ·
  day · brain · plan (stored); on the floating pill he keeps his own list and now has today.
