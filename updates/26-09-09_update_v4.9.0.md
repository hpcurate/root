- **The ring is kept as one of the four layouts.** "Add 3 layouts" reads as
  three *more*, and deleting the current drawing would take away the one that is
  already familiar. It stays as `ring` and is still the default; switching is
  one tap.
- **"Sensitive data for the current day"** is taken as **today's `log_<iso>`**.
  LOG is the record §10 calls private, and "the current day" is explicit.
  TRACK and STORE are private too but are not day-scoped, so there is no

- **Escape does `out` as well as the rebindable key.** The request asked for
  "another key to go back"; making Escape do it too means the way out is never
  a key you have to have bound.

## What was done

### The cursor — task 1

**It could not see half the app.** The selector knew about buttons, links and
fields. DO's routine cards are `<div onclick>`; TEND, CAL, CREATE and TOOLS all
dispatch off `data-act`. So "routines in do don't seem to register as an
element" was not a DO bug — none of those controls existed as far as the cursor
was concerned. `[onclick]` and `[data-act]` are in `FOCUSABLE` now, which fixes
DO and four other apps at once.

**It walks two levels.** 4.5 shipped one flat list, and on a dense screen that
is forty steps to the bottom — which is what "scrolls between elements
inconsistently" was describing. The cursor starts on a screen's blocks, the act
key steps into one, and up/down then walk that block's controls. Escape climbs a
level before giving up the cursor entirely.

**What a block is, is derived rather than listed.** A per-app list of container
classes would be ten things to keep in step and would go stale the first time a
screen was rebuilt. `blocksOf()` walks down from the screen through any run of
single-child wrappers — a lone `.cnt`, a lone grid — until it reaches a level
with more than one thing on it. That is the screen's own idea of its sections,
whatever the markup happens to be called.

**The mark replaced the ring.** A full accent outline around a *block* is an
outline around half the screen, and it reads as an error state rather than as a
cursor. The selection is a hairline wash now, and what you follow is a small
arrow hovering at its bottom-right corner: fixed, measured off
`getBoundingClientRect` so it follows an element of any shape, filled in and
turned 90° at the second level so the same object answers "which level am I
on". It is a child of `<body>`, not `#track` — §6.

**Seven rebindable keys** rather than five: `in` and `out` join `prev`, `next`,
`up`, `down` and `act`.

### Today's log on the Todoist route — task 2

`syncTodayPrivate`, off by default and **today only**, carried under its own
`today` key so an importer can drop it without unpicking the day.

The reasoning is on the panel rather than hidden behind a switch label: the
private route exists because a journal does not belong on someone else's server,
and the one honest exception is the day you are still in the middle of — which
is also the day a file you have not moved yet cannot help with.

Coming back it is merged by `mergeLogDay()` — per half, arrays unioned — not by
the Todoist route's rules, because it is a LOG record wherever it travelled. A
morning written on the phone and an evening on the laptop still arrive as one
day.

### TOOLS — task 3

Four drawings of one number:

- **ring** — the original, kept and still the default.
- **bar** — a departure board. Large tabular figures, left-aligned like
  something printed, a hairline under them filling left to right. Nothing
  encloses anything.
- **stack** — a column of twelve blocks filling from the bottom, with the time
  beside it rather than inside it. The readout as a quantity you can see across
  a room instead of a number to read. Each block decides whether it is lit by
  comparing its own index against the fraction, so it is one variable in and
  twelve decisions out with no JavaScript per block.
- **plain** — no container at all: the time very large, a word under it, one
  moving rule.

Every layout is handed the same 0-to-1 fraction and carries `#tl-big`,
`#tl-sub` and a `--tl-frac`, so `paint()` moves one number and one word and does
not care which drawing is on screen. That is what makes these four *layouts*
rather than four forks of the instrument. The phase colours moved off
`.tl-ring` onto the readout itself, so a layout never has to restate what colour
a break is.
