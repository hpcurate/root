# v2.21.1 — the :root block I split in half

## Request

> need a fix, undo all the changes to the fonts because now every text in the
> app is lowercase and the titles are miniscule

Reported directly rather than through the template — a regression from v2.21.0,
shipped an hour earlier.

## What was done

**It was not the fonts.** Adding the blur setting in 2.21.0, I opened the
override selector *inside* the `:root` block in `css/tokens.css`:

```css
  --chrome-blur:saturate(140%) blur(18px);
}                              /* ← :root closed here */
:root[data-chrome-blur="off"]{
  --chrome-blur:none;
  --nav-fh:58px;               /* ← everything below is now inside the override */
  --title-base:54px;
  --caps:uppercase;
  …
```

Every token declared after `--chrome-blur` — the shell metrics, `--title-base`,
`--caps`, the motion durations, `--readable` — ended up inside a rule that only
matches while blur is switched **off**. With blur on (the default) they were
undefined, so:

- `text-transform:var(--caps)` resolved to nothing → the whole app lower case
- `font-size:calc(var(--title-base) * var(--title-scale))` had no base → the
  wordmarks collapsed

The fix is one line in the right place: `:root` is whole again, and the
override is a standalone rule beside `[data-caps="off"]`, after the block
closes. No font, size or caps declaration was changed — none had been.

## Verification

`cd root/test && node harness.mjs` — **414 checks, 0 failures**, 3 new.

**The 411 checks of 2.21.0 all passed against the broken file**, which is the
part worth recording: jsdom does not cascade CSS, so a stylesheet can be
structurally wrong and every behavioural check stays green. The three new ones
read the file's *shape* instead, and fail against the broken version:

- every shell token (`--title-base`, `--caps`, `--nav-fh`, `--scr-pad-b`,
  `--t-fade`, `--readable`, `--chrome-blur`) is declared inside the `:root`
  block, found by matching `:root{` up to its first closing brace
- an override of one of them is a rule of its own, and no `:root[data-…]`
  selector exists
- the file's braces balance

Every other stylesheet was checked for the same fault; all twelve balance.
