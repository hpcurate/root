## What was done

### PLAN — the section boxes were clipping their own descenders (task 1)

`css/plan.css`. Every box on that screen carries `overflow:hidden`, which is
what stops a long section name pushing its row wider than the grid. Against
`line-height:1` that clip falls on the baseline, so the tail of a g, p, y or q
was sliced flat at the bottom of the box.

Five elements hide their overflow, and all five now carry a real line-height:
`.proj-sec` (and through it `.ps-name`) at 1.4, `.ps-n` at 1.4, `.proj-name` at
1.35, the open project's 24px heading at 1.3, and the date stepper's `.dstep-w`
/ `.dstep-d` at 1.35 / 1.4.

Nothing got taller for it: those rows are sized by `min-height: var(--tile-h)`
(46px) and their own padding, and the tallest of the five now measures 34.8px
inside that 46px.

**Decision made on Hugo's behalf:** the task named the section boxes. The same
defect is in the four sibling boxes on the same screen, from the same
`line-height:1` + `overflow:hidden` pair, so all five were fixed rather than
leaving four to come back as their own task later.

### DAY — a completion is written on its row (tasks 2 and 3)

`js/cal.js`, `css/cal.css`. 3.0.4 drew every completion as a mark floating at
the minute it happened. For a row ticked off the day itself that minute is
inside its own row, so the dot, the time and the name printed over the name
already there.

New `stampsFor()` matches today's marks against the visible rows — by name,
newest first, one mark to a row — and returns both the per-row times and the
set of marks that found a row. A matched completion is rendered *into* the row,
on its meta line, in the completion green with the same small dot the floating
mark wears. `markHTML()` is given that set and skips them, so nothing is drawn
twice.

`.ev-meta` is a flex row now rather than one clipped box: what the row is
shrinks and ellipses, the time never does.

What still floats is a completion with no row of its own — a block ticked on
DO, a `@quick` card. Those cross a row that is about something else by
definition, so `.cal-mark` is a 13px band of the page's ground centred on the
minute with a hairline in the completion colour, instead of `height:0` with the
row's text showing through the gaps between its chips.

### The mark around the selected tab — three dials (task 4)

`js/prefs.js`, `js/settings.js`, `css/shell.css`, `css/themes.css`. Under
appearance → layout → Navigation:

- **Selected tab** (`navShape`) — pill, rounded, square, circle, ring, underline
- **How it arrives** (`navAnim`) — grow, pop, fade, rise, none
- **Tab palette** (`tabPalette`) — app, warm, cool, candy, neon, mono

All three default to what the bar already looked like. `colorfulTabs` is
untouched and is still the gate the palette reads through, so an install that
had colour-coded tabs keeps them, in the hues it already had.

The indicator is now drawn once in `shell.css` from eight variables
(`--tab-c`, `--tab-ink`, `--tab-r`, `--tab-t`, `--tab-s0`, `--tab-y0`,
`--tab-dur`, `--tab-ease`); every option is a value swapped into those.

**A bug found on the way, and fixed:** an alerting tab did not wear the warning
colour when colour-coding was on — it alerted in its own app hue. The palette
claimed `background` on `::before` from a selector naming one app in one bar,
which outweighs `.tab-b.has-alert` and always will. The palette writes
`--tab-app-c` now and `--tab-c` falls back to it, so the two no longer compete;
this also carries the warning to ring and underline, which draw their colour as
a border rather than a fill.

**Decisions made on Hugo's behalf:** the task asked for "more colour palette
options", "options for the shape", and "animation options" without naming any.
Six palettes, six shapes and five animations were chosen; `mono` is a ramp cut
from `--tx` with `color-mix` rather than a set of hues, so it is the one palette
that works as well on a light theme as a dark one. Circle and underline fall
back to a box on the side rail above 880px, where a tab is a wide box and
neither shape survives being stood on its side.
